# English Glossary

All player-visible text in the game is English. Use these exact terms so the
same thing has the same name everywhere (shop, menus, toasts, codex,
speech bubbles, docs).

## Game and places
| Term | Notes |
|---|---|
| Abyssara – Deep Tide Tycoon | Game title |
| Tidal Market | The hub |
| Sun Zone, Twilight Zone, Midnight Zone, Hadal Depths | The four zones |
| Plot / Habitat | "your plot"; Habitat only in "Habitat Plot" |

## Currencies and items
| Term | Notes |
|---|---|
| Tide Coins | Main currency |
| Abyssal Shards | Premium-ish currency |
| Glow Spore(s) | Pickup on plots; Toxic Spore, Frozen Spore, Sunken Chest for event variants |
| Mystery Egg | Gacha egg |
| Rescue Token, Raid Skip, Instant Hatch | Developer products |

## Buildings
Glow Buoy Station, Brood Pool, Filter Plant, Anglerfish Tower, Coral Barrier,
Electric Eel Trap. Stages: "Stage 1/2/3". Brood Pool tiers: Basic, Advanced, Master.

## Rarities (display = id)
Common, Uncommon, Rare, Epic, Legendary, Mythic.

## Original creatures (id → display name)
GlowJelly → Glow Jelly, GlowShrimp → Glow Shrimp, GlowRay → Glow Ray,
Anglerfish → Anglerfish, BioluminescentEel → Bioluminescent Eel,
CrystalKraken → Crystal Kraken. Newer creatures already have English
display names in their model files and `docs/content-update-1.md`.

## Style
Short, friendly, kid-appropriate (ages 8–14). Title Case for buttons and
panel titles, sentence case for messages. No German left in any string a
player or the developer console can see.
